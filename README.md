# 롯데웰푸드 K-푸드 수출 유망국가 발굴 AI 에이전트

LOTTE AX Challenge 2026 · 롯데웰푸드 [식품] 과제 「K-푸드 수출 유망국가 발굴」 데모

제품을 고르면 공개 무역 통계로 국가별 점수를 계산하고, **우선 검토 후보 TOP3**와 근거·한계·출처를 담은 보고서를 만듭니다.

## 핵심 원칙

- **숫자는 코드가, 해석은 AI가.** 점수와 순위는 Python 코드(`calc.py`)가 계산하고, AI는 그 결과(JSON)만 근거로 보고서를 씁니다.
- **AI 보고서 숫자 검증.** AI가 쓴 보고서에 계산 결과에 없는 숫자가 하나라도 있으면 보고서를 폐기하고 규칙 기반 보고서로 대체합니다.
- **결측값을 0으로 처리하지 않음.** 자료가 없으면 "산정 불가", 기준연도 자료가 없으면 직전 연도로 대체하고 그 사실을 표시합니다.
- **"진출 가능"이 아니라 "우선 검토 후보".** 관세·인증·물류·수익성 등 검토 항목은 확인 전까지 "미확인"으로 표시합니다.

## 작동 방식

```
요청 해석 (OpenAI 함수 호출 / 키가 없으면 규칙 기반)
   → 계산 도구 호출 (calc.py, AI 미사용)
   → 한계 점검 (checks.py: 결측·기준연도 불일치·분류 관행 차이·중계무역 거점)
   → 출처 달린 보고서 (AI 작성 + 숫자 검증)
```

## 분석 기준

| 구분 | 내용 | 기본 가중치 |
|---|---|---|
| ① 시장 수요 | 해당 품목 국가별 수입 규모 + 연평균 성장률(2019–2024) | 0.45 |
| ② 한국산 교역 실적 | 한국의 해당 품목 국가별 수출 규모 + 성장률 | 0.40 |
| ③ 구매력 | 1인당 GDP | 0.15 |

- 후보국: 품목별 수입 상위 30개국 ∪ 한국 수출 상위 20개국 (한국 제외)
- 점수: 후보국 안에서의 백분위(0–100)를 가중 평균
- 민감도: 각 가중치를 ±20% 바꿔 TOP3가 유지되는지 확인
- 비교 기준: 단순 수입액 순위를 함께 표시

## 제품

| 제품 | 품목번호(HS) | 비고 |
|---|---|---|
| 빼빼로 | 1905.31 / 1905.90 | 공개 수출 실적과 단일 품목번호 통계의 차이가 커서 두 번호로 **각각** 순위를 내고 비교. 두 기준 모두 상위 10위 = 견고한 후보 |
| 아이스크림 | 2105.00 | 한국 전체 빙과 수출 통계이며 롯데 실적이 아님 |

## 시험 결과 (2024년 기준, 기본 가중치)

- **빼빼로:** 두 품목번호 순위상관 0.635, 상위 10개국 중 7개국 공통. TOP3 = 네덜란드(유통 거점 후보), 미국, 캐나다. 가중치 ±20%에도 TOP3 구성 유지.
- **아이스크림:** TOP3 = 미국, 호주, 네덜란드(유통 거점 후보). 가중치 ±20%에도 구성·순서 유지.

네덜란드는 중계무역 거점이라 수입액에 재수출 물량이 포함될 수 있어, "유통 거점 후보"로 따로 표시합니다.

## 실행 방법

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

OpenAI 보고서를 쓰려면 실행 전에 환경 변수로 키를 지정합니다. 키가 없으면 규칙 기반 보고서로 작동합니다.

```powershell
$env:OPENAI_API_KEY="..."   # 키는 파일에 저장하거나 저장소에 올리지 않습니다
```

화면 없이 확인:

```powershell
py calc.py pepero
py agent.py 아이스크림 기존 시장 확대
```

## 파일 구조

| 파일 | 역할 |
|---|---|
| `calc.py` | 점수·순위·민감도 계산 (AI 미사용) |
| `checks.py` | 결측·기준연도 불일치·분류 관행 차이 점검, 순위상관 |
| `agent.py` | 요청 해석, 보고서 작성, 숫자 검증 |
| `app.py` | Streamlit 화면 |
| `products.json` | 제품 프로필 (품목번호, 검토 항목) — 제품 추가 시 이 파일만 수정 |
| `data/` | 무역·GDP 통계 CSV, 국가명, 롯데 판매 공개 근거 |

## 데이터 출처

- UN Comtrade 공개 API — 국가별 수입(상대국: World), 한국 수출(상대국별). 단위: 천 달러 → 달러 환산
- World Bank — 1인당 GDP (NY.GDP.PCAP.CD)
- 롯데 판매 근거: 공개 언론 보도 (`data/lotte_presence.json`, 확인일 2026-10-31). 근거가 없는 국가는 "미확인"이며 미진출을 뜻하지 않습니다.
